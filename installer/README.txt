DOMEO · Подбор по корзине — установка (Chrome / Яндекс.Браузер)
===============================================================
Автоустановка и автообновление через политику браузера. Бесплатно.

УСТАНОВКА (один раз)
--------------------
1. Двойной клик по «Установить.bat» → подтвердите запрос «Разрешить изменения»
   (нужны права администратора — политика пишется в систему).
2. Полностью перезапустите Chrome / Яндекс.Браузер (закрыть все окна и открыть снова).
3. Расширение появится само — иконка на панели.

ОБНОВЛЕНИЯ
----------
Автоматические. Браузер сам проверяет и ставит новые версии — ничего делать не нужно.

УДАЛЕНИЕ
--------
Двойной клик по «Удалить.bat» (от администратора) → перезапустить браузер.

ТРЕБОВАНИЯ
----------
- Chrome или Яндекс.Браузер.
- Права администратора в момент установки.
- Интернет (расширение и обновления скачиваются с нашего GitHub).

ПРИМЕЧАНИЕ
----------
Расширение ставится как «управляемое политикой» — пользователь не может его
отключить/удалить через меню (убирается только через «Удалить.bat»). Это норма
для корпоративной установки.
