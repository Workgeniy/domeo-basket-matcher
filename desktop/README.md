# DOMEO · Подбор по корзине — десктоп

Electron-приложение: читает корзину поставщика (Петрович / ВсеИнструменты / Lemana)
во встроенном окне браузера, подбирает аналоги в store.domeo.ru (Diginetica),
собирает корзину (`ADD2BASKET`) и выдаёт ссылку `/basket/share/?code=...`.

## Как пользоваться (установленная версия)
1. Открыть приложение «DOMEO Podbor».
2. Справа во встроенном окне открыть корзину поставщика (кнопки-ярлыки сверху слева
   или вставить ссылку). При необходимости — войти в DOMEO в этом же окне (сессия
   сохраняется между запусками).
3. «Прочитать корзину из окна →» — приложение разберёт позиции и подберёт аналоги.
4. Проверить/поправить выбор в списке.
5. «Собрать корзину в DOMEO» — товары добавятся, появится ссылка на корзину.

Словарь соответствий и история хранятся локально (в профиле пользователя).

## Разработка
```
cd desktop
npm install
npm start
```

## Сборка установщика
Локально (без публикации):
```
npm install
npm run dist     # => desktop/release/DOMEO-Podbor-Setup-<version>.exe
```

Публикация релиза с автообновлением — через GitHub Actions:
подними версию в `package.json`, создай тег `vX.Y.Z` и запушь его —
workflow `desktop-release` соберёт установщик и выложит в Releases вместе с `latest.yml`.

Автообновление: приложение проверяет GitHub Releases при старте и по кнопке
«Обновления»; новую версию скачивает и ставит по кнопке «Перезапустить и обновить».

> Приложение не подписано сертификатом — при первом запуске Windows SmartScreen
> может предупредить («Подробнее» → «Выполнить в любом случае»). Автообновление
> на Windows при этом работает.
