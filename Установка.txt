DOMEO · Подбор по корзине — установка (Chrome / Яндекс.Браузер)
================================================================

УСТАНОВКА (один раз, ~3 клика)
------------------------------
1. Распакуйте этот архив в удобную папку (например, в Документы).
   ВАЖНО: не удаляйте папку после установки — расширение работает из неё.
2. Откройте в браузере:  browser://extensions   (в Chrome: chrome://extensions)
3. Включите «Режим разработчика» (переключатель справа вверху).
4. Нажмите «Загрузить распакованное расширение» и выберите папку extension.
5. Иконка появится на панели — можно закрепить.

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Войдите в store.domeo.ru под своим логином.
2. Откройте корзину поставщика (Петрович / ВсеИнструменты / Lemana).
3. Нажмите иконку расширения → «Прочитать корзину» → пойдёт подбор.
   (Или вставьте список в поле и нажмите «Подобрать из поля».)
4. Проверьте кандидатов, при необходимости смените в выпадающем списке.
5. «Собрать корзину в DOMEO» → товары добавятся, появится ссылка на корзину.

ОБНОВЛЕНИЕ
----------
Когда расширение покажет «Доступна новая версия»:
1. Двойной клик по «Обновить.bat» в этой папке — он скачает свежую версию.
2. Откройте browser://extensions и нажмите «Обновить» на карточке расширения DOMEO.
Нужен интернет. Python не требуется (используется встроенный PowerShell).

ТРЕБОВАНИЯ
----------
- Chrome или Яндекс.Браузер.
- Для обновления — доступ в интернет.
