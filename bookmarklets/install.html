Закладки «DOMEO · Подбор по корзине»

Работают в любом браузере (Chrome, Яндекс, Firefox, Safari, Edge).

Как установить

  1. Включите панель закладок (Ctrl+Shift+B).
  2. Перетащите жёлтую кнопку ниже на панель закладок.
  3. Готово — кнопка появится на панели.

Если перетащить не получается: правый клик по панели → «Добавить страницу…», в адрес вставьте строку из файла bookmarklet.txt / cart.txt.

1. Прочитать корзину

На странице корзины поставщика (Петрович / ВсеИнструменты / Lemana) — читает позиции и копирует их.

Прочитать корзину → DOMEO

2. Собрать корзину

На store.domeo.ru (под своим логином) — собирает корзину из подобранного списка и даёт ссылку.

Собрать корзину в DOMEO

Подбор делает веб-приложение (открывается отдельной ссылкой). Полный порядок: прочитать корзину → вставить в приложение → подобрать → скопировать список → собрать корзину.
